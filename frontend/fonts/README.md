# Local typefaces

QueryTrace serves these fonts from its own origin. No Google Fonts or Taste
request is needed at runtime. `font-display: swap` keeps fallback text visible.

- **Inria Serif**, regular 400: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/inriaserif), [SIL OFL](Inria-Serif-OFL.txt).
- **Inter**, variable normal 400–600: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/inter), [SIL OFL](Inter-OFL.txt).

WOFF2 files were obtained from the official Google Fonts CSS API on 2026-10-09:
`https://fonts.googleapis.com/css2?family=Inria+Serif:wght@400&family=Inter:wght@400..600&display=swap`.
Latin and Latin Extended subsets total 156,808 bytes; Unicode ranges load only
needed subsets. The common Latin pair totals 64,192 bytes and is preloaded.
Other scripts use the system fallback. Code and technical identifiers use a
system monospace font. The fonts are unmodified; license notices are preserved.
