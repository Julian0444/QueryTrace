Upload a document

Upload a document (.pdf, .txt, .md, .docx) with metadata. The server validates and extracts the file, then publishes a consistent corpus version. Identical content is rejected as a duplicate. Indexing progress appears below.

Demo only: uploads are persisted to the local repo (corpora/<workspace>/ and artifacts/<workspace>/). Ephemeral hosting filesystems will lose uploaded docs on container restart. No delete or edit path — indexing runs as a background job. DOCX paragraphs, tables, headers and footers are extracted. Scanned PDFs and embedded images need text/OCR before upload; review any extraction warnings.
